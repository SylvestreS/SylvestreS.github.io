学完稳定币之后，代币化（Tokenization）这个概念几乎是水到渠成的。

## 一句话定义

**代币化 = 把某项资产（或它的收益权、所有权凭证）转换成区块链上的代币，让这项权利可以被分割、被转让、被编程。**

注意「可以被编程」这几个字。这才是代币化相对传统证券登记最有意思的地方——传统资产的所有权规则写在法律文件里，靠人执行；代币化之后，部分规则可以写进合约代码，自动执行。

## 技术上其实很短

一个最简化的同质化代币（ERC-20 标准），核心就是这么点东西：

```solidity
contract MyToken {
    string public name = "Building Share";
    string public symbol = "BLDG";
    uint8  public decimals = 18;
    uint256 public totalSupply;

    mapping(address => uint256) public balanceOf;

    constructor(uint256 _supply) {
        totalSupply = _supply;
        balanceOf[msg.sender] = _supply;
    }

    function transfer(address to, uint256 amount) public {
        require(balanceOf[msg.sender] >= amount, "余额不足");
        balanceOf[msg.sender] -= amount;
        balanceOf[to] += amount;
    }
}
```

一个记账表（`balanceOf`）、一个转账函数，完事。**从代码角度看，「代币化一栋楼」和「发一个积分」没有任何区别**——都是这个 mapping 里的一串数字。

这个事实让我意识到一件重要的事：**代币化的全部难点，都在这段代码之外**。

## 三个真正的问题

### 一、法律确权：代币到底代表什么

持有 1 枚 BLDG，你拥有什么？

- 这栋楼的 1/1,000,000 产权？
- 还是对某个持有这栋楼的公司（SPV）的股权？
- 还是仅仅一份「收益权」——收租金的时候有你一份，但楼不是你的？

这三种设计在法律上完全不同，破产时的清偿顺序也不同。而链上的代币长得一模一样。**代币本身不携带法律含义，含义写在链下的招募说明书和法律意见书里**。

这就是为什么证券型代币需要专门的标准（ERC-1400、ERC-3643）——它们要能在链上表达「这个地址通过了 KYC」「这笔转账被允许」这类合规约束。

### 二、托管：链下的东西由谁看着

链上代币和链下资产之间，需要一个**托管人（Custodian）**。

托管人是整个结构里的信任中心。于是你会发现一个有点讽刺的事实：**一个号称去信任化的链上代币，它的价值完全依赖于一个链下的、需要被信任的机构**。

所以评估一个 RWA 项目，第一个该问的问题不是「用的哪条链」，而是「托管人是谁、受谁监管、能不能破产隔离」。

### 三、赎回：怎么变回真钱

这是最容易被跳过、但最要命的一环。

持有者想把代币换回现实资产或现金，通道是什么？

- 随时赎回，还是只有特定窗口期？
- 赎回价格按什么算？（净值？市价？）
- 如果托管人出问题，赎回权还在不在？

链上交易可以 7×24 秒级结算，但**赎回通道往往受银行营业时间、基金申赎规则、跨境转账限制约束**。这个「最后一公里」的摩擦，是 RWA 目前最真实的瓶颈。

## 同质化 vs 非同质化：所有权怎么表达

| | 同质化（Fungible） | 非同质化（Non-Fungible） |
| --- | --- | --- |
| 标准 | ERC-20 | ERC-721 |
| 单位之间 | 完全等价，可互换 | 各不相同，不可互换 |
| 适合 | 货币、基金份额、分割产权 | 特定资产、凭证、唯一编号的合约 |
| 类比 | 钞票 | 房本 |

选择哪个，取决于你想表达的权利是**可替代的数量**还是**唯一的标的**。很多 RWA 项目会两者混用：基金份额用 ERC-20，底层那一份具体的资产凭证用 ERC-721。

## 一张图总结代币化的结构

```
链下世界                          链上世界
─────────                        ─────────
现实资产（楼 / 国债 / 基金）
   │
   │  ① 法律结构（通常是 SPV）
   ▼
法律上的权利凭证
   │
   │  ② 托管（受监管的托管人持有）
   ▼
托管证明 / 审计报告 ──────────▶ 预言机（Oracle）
                                    │
                                    ▼
                              智能合约（代币）
                                    │
                                    ▼
                              你钱包里的代币
```

三条虚线，就是三个风险点。**技术只负责最右边那一格。**
